# MouseBattery · Windows 11 外设电量工具

在任务栏上横向显示鼠标和键盘的电量，不用一直开着设备驱动网页。

```text
鼠标  88%  ━━━━━━━━    │    键盘·充电  79%  ━━━━━━━
```

当前版本：**1.1.2**。界面使用 WPF、Win32 和系统托盘，源码没有第三方 NuGet 依赖。

## 功能

- 鼠标、键盘横向并排，18 DIP 大字号百分比，各自保留电量条；低于或等于 20% 时显示橙色。
- 每 30 秒自动刷新，也可手动刷新；两台设备分别查询和处理错误。
- 点击卡片打开详情，查看设备型号、充电状态、数据来源及更新时间。点击窗口外自动收起，卡片继续显示。
- 支持拖动、锁定位置、多屏选择，以及浅色／深色／跟随系统。
- 提供系统托盘入口和可选的登录启动开关，默认不开启登录启动。
- 休眠或断连显示 `—`；详情里的上次结果会标记为“非实时”。
- 详情最小化保留任务栏图标，重复启动恢复已有详情；菜单“退出”结束后台进程。

任务栏卡片是对齐任务栏的独立覆盖窗口，不会自动给其他任务栏按钮腾出空间。可拖到空白区域，再锁定位置。目标屏全屏或任务栏自动隐藏时，卡片按对应状态隐藏。

## 已验证设备

| 设备 | 已验证连接与标识 |
| --- | --- |
| ROG 月刃2 RGB / KERIS II ORIGIN | ROG OMNI RECEIVER：`0B05:1ACE`，配对 PID `1C0E` |
| CHERRY MX 10.1 | USB 接口：`046A:01EF`，厂商自定义 HID 集合 |

电量通过本地 HID 查询，不要求 Gear Link 网页或 CHERRY Utility 持续运行。其他 CHERRY 型号、蓝牙直连、其他 ASUS 接收器与 ASUS 有线直连尚未验证或实现。

查询协议与实际兼容范围见 [设备协议说明](docs/protocols.md)。程序只查询状态，不修改设备配置。

## 运行

需要 **Windows 11 x64** 和 **.NET 9 Windows Desktop Runtime x64**。

构建后启动：

```powershell
.\dist\MouseBattery.exe
```

保留同目录中的 DLL 和 JSON 文件。单击卡片或托盘打开详情，右键打开设置菜单。托盘数字沿用鼠标电量，悬停提示同时列出两台设备。

默认位于同屏 AI 用量卡片左侧；没有该卡片时使用任务栏左侧的默认位置。解锁后按住卡片左右拖动，右键“固定位置”可锁定。

## 构建与检查

安装 .NET 9 SDK，在仓库根目录运行：

```powershell
# 26 项纯协议解析检查，不访问硬件。
dotnet run --project tests/ProtocolChecks.csproj -c Release

# 发布到 dist/。更新前请先通过菜单退出正在运行的版本。
.\build.ps1

# 也可发布到单独目录，避免覆盖运行中的程序。
.\build.ps1 -OutputDirectory .\artifacts\publish-check
```

`global.json` 允许使用已安装的 .NET 9 SDK 功能更新版本。发布方式使用系统已安装的 Desktop Runtime，不内嵌运行时。

```text
src/                 应用界面、窗口定位与设备读取器
tests/               纯协议解析检查
docs/protocols.md    已验证的设备协议
build.ps1            Windows x64 发布入口
dist/                本地运行文件，已排除 Git
artifacts/、work/     本地构建、备份和排查文件，已排除 Git
```

## 设置与诊断

个人设置和运行状态保存在 `%LOCALAPPDATA%\MouseBattery`：

| 文件 | 用途 |
| --- | --- |
| `preferences.json` | 主题、显示器、偏移、位置锁定 |
| `status.json` | 两台设备的最新读取状态和错误 |
| `error.log` | 读取失败记录，自动限制大小 |

更换程序位置后，如已启用登录启动，请在新位置关闭、重新开启一次该选项。

| 参数 | 行为 |
| --- | --- |
| `--details` | 打开或恢复详情 |
| `--menu` | 打开菜单 |
| `--exit` | 正常退出已有实例 |
| `--diagnose` | 本地枚举 HID 并查询设备，生成 `diagnostic.txt` |
| `--inspect-ui` | 界面排查模式，将卡片作为可检查窗口显示 |

诊断文件可能包含本机设备路径，只用于本地排查。个人设置、日志、诊断、安装包及临时分析依赖均已排除 Git。

## 实现说明

- UI 使用 WPF，任务栏定位和层级维护使用 Win32，托盘使用 NotifyIcon。
- 显示器选择保存物理标识；显示设置变化或唤醒后重新定位。
- 详情收起、前台切换和任务栏重排时立即维护卡片层级，避免等待下一次一秒定时更新。
- 鼠标与键盘读取器有独立的成功状态和错误，异步结果回到 UI Dispatcher。
- 不注入或修改 Explorer，不附带厂商程序、驱动、DLL 或固件。
