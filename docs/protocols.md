# 设备查询协议

两个读取器分别查询、分别保存最后成功结果，单个设备休眠、断开或超时不会清空另一台设备的电量。请求超时为 1.6 秒，自动刷新周期为 30 秒。

## ASUS ROG OMNI

已验证 ROG OMNI RECEIVER（VID `0B05` / PID `1ACE`）与 ROG 月刃2 RGB / KERIS II ORIGIN（配对 PID `1C0E`）。

协议线索来自 [ASUS Gear Link](https://gearlink.asus.com/zh-cn) 于 2026-11-06 提供的公开设备模块 `/view/6862/manifest.json`（1.00.24）和对应 preload bundle。程序独立实现协议，不执行网页代码。

| 查询 | 报文前缀 | 作用 |
| --- | --- | --- |
| 配对清单 | `A0 00 00 00` | 获取配对 PID、控制报告与通知报告 ID |
| 鼠标在线状态 | `12 00 02 00` | 区分已连接与休眠／关闭 |
| 鼠标电量 | `12 07 00 00` | 获取百分比、充电状态和电压 |

使用鼠标控制报告 3、通知报告 5。解析器检查命令头、清单边界、电量范围和充电状态，不把键盘响应当成鼠标电量。

## CHERRY MX 10.1

根据本机已安装 CHERRY Utility Software 的只读 `HidReadPower` 实现核对，并在 MX 10.1 的屏幕上核对了实际电量。

读取器限定 VID `046A`、PID `01EF`、Usage Page `FF1C`、Usage `0092`，输入和输出报告均为 64 字节。它不打开键盘按键输入集合。

唯一发送的请求为以下前缀，其余字节为 0：

```text
04 20 00 1A 06 00 00 00
```

请求字节 1–2 是字节 3–63 的校验和，回复保留此前 7 字节的命令头。

| 回复位置（从 0 开始） | 含义 |
| --- | --- |
| 7 | 查询结果；本实现只接受成功值 0 |
| 8 | 剩余电量，必须为 0–100 |
| 9 | 充电状态；0 为未充电，1／2 为充电 |

读取器丢弃其他命令的回复，验证长度、范围及状态。不将不相关 Feature 报告中的任意字节解释为电量。

## CHERRY MX 10.0 RGB（有线）

实机枚举确认 VID `046A`、PID `00BB`；标准键盘集合为 Usage Page `0001`、Usage `0006`。[CHERRY 官方有线产品声明](https://www.cherry.de/index.php?eID=downloadFile&f=983&token=2b678e962472dcc395efcfe64ca9c09af9a7b78d) 将 MX BOARD 10.0 列为有线产品。

该型号通过 USB 供电，不提供电池百分比。读取器只枚举已连接的键盘集合，返回“有线 / USB 供电”，不打开按键输入流，也不发送任何电量查询。虽然它同样存在 `FF1C:0092`、64 字节的厂商集合，仍不能据此套用 MX 10.1 的命令；设备过滤必须同时匹配 PID。

MX 10.0 与 MX 10.1 同时连接时优先显示 MX 10.0。断开后主卡片显示 `—`，历史状态在详情标为非实时；重连后在下一次刷新恢复。

## 查询范围

这些适配器只读取设备状态，不修改 DPI、灯效、按键、宏、固件或配对。工程不附带厂商程序、DLL 或固件。

纯解析检查使用脱敏的真实回复，覆盖配对过滤、请求校验和、响应头、充电状态、0%／100%、截断、无效值和设备错误响应；设备检查覆盖两种 CHERRY 型号的集合过滤、有线状态和低电量与无电池的区别。
